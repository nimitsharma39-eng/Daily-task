# Daily Task List

A clean, responsive, single-file daily task manager built with HTML, Tailwind CSS, and vanilla JavaScript.

## Features
- Task creation, completion toggling, and deletion
- Persistent browser storage via `localStorage`
- Filter tabs: All, Active, Completed
- One-click "Clear Completed" cleanup
- Animated daily completion progress bar
- Priority badges (High, Medium, Low)
- Dark mode with system preference auto-detection
- Inline double-click task editing
- JSON backup export and import
- Due dates with "Today", "Overdue", and upcoming badges
- Celebratory confetti & Web Audio chime on 100% completion
